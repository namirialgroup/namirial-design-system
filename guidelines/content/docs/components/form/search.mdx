## Overview

The Search component helps users quickly find items within a large or unstructured collection. Instead of choosing from a predefined list, users enter a search term to filter or locate relevant results.

### When to use
Use the Search component when:
- Users need to filter tables, lists, or catalogs based on their input.
- Users need to search across content, commands, or resources, such as in a global search or command palette.
- The collection is too large to browse efficiently, for example when finding contacts, templates, documents, or products.

## Sizes

## Accessibility

#### Semantics

- Use `<input type="search">` — it gets the platform's native clear affordance on some browsers and is announced correctly by assistive tech.
- If results update live below the field, mark the results container with `aria-live="polite"` so screen reader users hear the match count change.

#### Keyboard

- Escape clears the field when it has focus and a value (mirrors native `type="search"` behavior in most browsers — replicate it if you intercept the keydown).
- Arrow Down from the field should move focus into the results list when one is open.

#### Labeling

- A search field with no visible label still needs one — use `aria-label="Search documents"` or a visually-hidden `<label>`.
- The clear button requires `aria-label="Clear search"`; the icon alone isn't accessible.

## Implementation

Search is markup-only for the base field. Live filtering and the results dropdown need a small amount of JavaScript to wire input events to your data source.

```html
<link rel="stylesheet" href="namirial-theme.css">

<div class="nm-input nm-input--md">
  <div class="nm-input__container">
    <span class="nm-input__icon-leading"><!-- search icon --></span>
    <input type="search" class="nm-input__field" placeholder="Search documents" aria-label="Search documents">
  </div>
</div>
```

#### CSS classes

| Class | Values | Default |
|-------|--------|---------|
| `nm-input--{size}` | xs · md · lg · xl — omit for the `sm` default | — (`sm`) |
| `nm-input__icon-leading` | Houses the search glyph | — |
| `nm-input__icon-trailing` | Houses the clear button — mount conditionally | — |
