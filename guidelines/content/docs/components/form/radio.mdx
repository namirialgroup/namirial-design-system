## Overview

A radio group forces a single choice among a small, fully-visible set of options. Unlike a checkbox, clicking a radio never toggles it off — it only becomes unselected when a sibling in the same group is selected. There is no mixed state: exactly one radio in a group is checked once a default has been set.

### When to use

- Exactly one choice from 2–5 mutually exclusive, always-visible options (`Monthly` / `Annual`, `Small` / `Medium` / `Large`)
- When you want every option visible at once, so the user can compare them before choosing

### When not to use

- More than ~5 options — use a **select** instead so the list doesn't dominate the page.
- Multiple options can be true at once — use **checkboxes**.
- A compact, icon-forward mode switch with 2–4 options — a **segmented control** reads faster.

#### No disabled state

Radios never ship the native "greyed out" disabled look. If an option is off the table for now, use **read-only** so its selection state stays legible and its value still submits with the form.

#### Read-only implementation

`readonly` has no native effect on `<input type="radio">`. Pair `.is-readonly` with `tabindex="-1"` and `aria-readonly="true"` — the class handles the visual, `pointer-events: none` blocks clicks, and removing it from the tab order blocks keyboard activation:

```html
<input type="radio" name="plan" class="nm-radio is-readonly" checked readonly tabindex="-1" aria-readonly="true">
```

## Radio groups

Radios only behave as a mutually-exclusive set when they share the same `name`. Wrap the group in a `<fieldset>` with a `<legend>` so assistive tech announces what's being chosen.

<div className="example stacked">
  <fieldset style={{border:'none',padding:0,margin:0,display:'flex',flexDirection:'column',gap:'12px'}}>
    <legend style={{fontSize:'13px',fontWeight:600,marginBottom:'4px',padding:0}}>Billing period</legend>
    <label className="nm-choice-field"><input type="radio" name="billing" className="nm-radio" defaultChecked /><span className="nm-choice-field__label">Monthly</span></label>
    <label className="nm-choice-field"><input type="radio" name="billing" className="nm-radio" /><span className="nm-choice-field__label">Annual <span className="nm-choice-field__optional">(save 20%)</span></span></label>
  </fieldset>
</div>

Once one radio in a `name` group is focused, arrow keys move selection between siblings — this roving behavior is native to `<input type="radio">` and needs no JavaScript.

## Accessibility

#### Semantics

- Give every radio in a group the same `name` — this is what makes them mutually exclusive and is what screen readers rely on to report "2 of 4," etc.
- Wrap the group in `<fieldset>` + `<legend>`, naming the question being answered ("Billing period," not "Options").

#### Keyboard

- Tab moves to the group once, landing on the checked radio (or the first, if none is checked yet).
- Arrow keys move selection between radios in the same group — native browser behavior, no JavaScript required.
- Focus uses `:focus-visible`, so the ring appears on keyboard focus but not on mouse click.

#### Read-only

- Native `readonly` has no effect on radios. Pair `.is-readonly` with `tabindex="-1"` and `aria-readonly="true"` so it's fully inert while its value still submits with the form.

#### Labeling

- Never rely on color alone — the filled bullet is the primary signal, but make sure the label text also makes the selected option obvious out of context.

## Implementation

No JavaScript component is required — a radio group is a set of native `<input>` elements sharing a `name`, styled by CSS classes.

```html
<link rel="stylesheet" href="namirial-theme.css">

<fieldset>
  <legend>Billing period</legend>
  <label class="nm-choice-field">
    <input type="radio" name="billing" class="nm-radio" checked>
    <span class="nm-choice-field__label">Monthly</span>
  </label>
  <label class="nm-choice-field">
    <input type="radio" name="billing" class="nm-radio">
    <span class="nm-choice-field__label">Annual</span>
  </label>
</fieldset>
```

#### CSS classes

| Class | Values | Default |
|-------|--------|---------|
| `nm-radio` | Base class — fixed 24×24px, no size modifiers | — |
| `:checked` | Selection = on | unchecked |
| `[readonly]` / `.is-readonly` | Read-only — pair with `tabindex="-1"` | — |
| `nm-choice-field__required` | Marks a field as required | — |
| `nm-choice-field__optional` | Marks a field as optional | — |
