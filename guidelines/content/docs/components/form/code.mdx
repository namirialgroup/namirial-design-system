## Overview

A code field exists for exactly one job: verifying that the user has access to something out-of-band — an SMS, an authenticator app, an email. Every cell holds exactly one character, so correctness is visible before the code is even submitted.

### When to use

- One-time passwords (OTP) sent by SMS, email, or an authenticator app
- A short numeric PIN a user sets and re-enters
- A signing confirmation code embedded in a document workflow

### When not to use

- Any value longer than ~8 characters — a single **input** with `letter-spacing` and a monospace font reads better than a wall of cells.
- Free-form text of any kind — use **input**.
- A value the user selects rather than types — use **select**.

## Behavior

A code field needs a small amount of JavaScript beyond CSS: typing a digit should auto-advance focus to the next cell, Backspace on an empty cell should move focus back, and pasting a full code should split it across every cell.

```js
const cells = Array.from(row.querySelectorAll('.nm-input__field'));

cells.forEach((cell, i) => {
  cell.addEventListener('input', () => {
    cell.value = cell.value.replace(/\D/g, '').slice(0, 1);
    if (cell.value && cells[i + 1]) cells[i + 1].focus();
  });
  cell.addEventListener('keydown', (e) => {
    if (e.key === 'Backspace' && !cell.value && cells[i - 1]) cells[i - 1].focus();
  });
  cell.addEventListener('paste', (e) => {
    const digits = e.clipboardData.getData('text').replace(/\D/g, '').split('');
    if (digits.length < 2) return;
    e.preventDefault();
    digits.slice(0, cells.length).forEach((d, j) => { cells[j].value = d; });
    cells[Math.min(digits.length, cells.length) - 1].focus();
  });
});
```

Validate and submit only once every cell is filled — don't ask the user to press a separate "Verify" button for a 4–6 digit code if you can submit automatically on completion.

## Accessibility

#### Semantics

- Use `<input inputmode="numeric" pattern="[0-9]*" maxlength="1">` per cell so mobile keyboards default to a numeric pad.
- Wrap the row in a `<fieldset>` with a `<legend>` describing what the code is for ("Verification code sent to your phone").

#### Keyboard

- Auto-advance and auto-retreat (described in [Behavior](#behavior)) must not trap focus — Tab and Shift+Tab should still move a keyboard user through cells normally if they choose not to type sequentially.
- Paste-splitting must not break the browser's native paste handling for users who paste one cell at a time.

#### Labeling

- Announce validation results in an `aria-live="polite"` region near the field — don't rely on color or shake animation alone.
- Give the fieldset an `aria-describedby` pointing at any help or countdown text ("Code expires in 4:59").
