## Overview

A toast confirms that something just happened — a save, a send, an undo window — without interrupting the user's flow. It appears near a screen edge (commonly bottom-right), stacks with other toasts, and dismisses itself after a few seconds or when the user closes it.

### When to use

Use a toast when:

- You need to confirm the result of an action the user just took, and the confirmation doesn't need to persist.
- The notification is independent of scroll position — it should stay visible even if the triggering element scrolls out of view.

Consider another component when:

- The information must stay visible until the user acts on it — use [Alert](/docs/components/messaging/alert).
- The feedback is tied to a specific spot in the layout rather than floating at a screen edge — use [Message](/docs/components/messaging/message).
- The action needs explicit confirmation before it happens (not after) — use a [Confirmation Dialog](/docs/components/messaging/dialogs).

## Accessibility

#### Semantics

- Render the toast region with `role="status"` (`aria-live="polite"`) for routine confirmations, or `role="alert"` (`aria-live="assertive"`) for failures that need immediate attention.
- Mark the icon `aria-hidden="true"`.

#### Timing & dismissal

- Give the user enough time to read the message before auto-dismissing — don't use a fixed short timer regardless of content length; pause the timer on hover/focus.
- Always provide a manual close button in addition to any auto-dismiss timer — some users need more time or use assistive tech that doesn't race the clock.

#### Focus

- A toast must never steal keyboard focus on appearance — it's a passive notification, not an interruption.
- Any action button inside it must still be reachable by keyboard for users who choose to engage with it.

## Implementation

Auto-dismiss timing and stacking multiple toasts need JavaScript; the card itself is pure CSS.

```html
<link rel="stylesheet" href="namirial-theme.css">

<div class="nm-toast nm-toast--positive" role="status" aria-live="polite">
  <div class="nm-toast__notification">
    <span class="nm-toast__icon" aria-hidden="true"><!-- icon --></span>
    <div class="nm-toast__text">
      <span class="nm-toast__title">Invoice sent</span>
      <span class="nm-toast__body">Delivered to client.</span>
    </div>
    <button type="button" class="nm-toast__close" aria-label="Dismiss"><!-- x icon --></button>
  </div>
  <div class="nm-toast__actions">
    <button type="button" class="nm-button nm-button--ghost nm-button--secondary nm-button--sm">View invoice</button>
  </div>
</div>
```

#### CSS classes

| Class | Values | Default |
|-------|--------|---------|
| `nm-toast--{intent}` | primary · secondary · accent · info · positive · negative · warning — omit for `primary` | — (`primary`) |
| `nm-toast__notification` | Icon + text + close row | — |
| `nm-toast__actions` | Bottom action row, right-aligned | — |
| `nm-toast__close` | Dismiss button, 24×24px, must be a `<button>` | — |
