## Overview

A message is a compact, self-sized snippet of feedback — it hugs its content instead of stretching full-width like an alert, and it floats with a shadow rather than sitting flush in the layout. It's meant to sit near what it describes: beside a button, under a small action row, next to a list item.

### When to use

Use a message when:

- The feedback is short (a few words) and tied to a specific, local action or spot on the page.
- You want a floating, self-contained snippet rather than a full-width banner.

Consider another component when:

- The message applies to the whole page or section — use [Alert](/docs/components/messaging/alert) instead.
- The feedback should appear briefly and disappear on its own, independent of scroll position — use [Toast](/docs/components/messaging/toast).
- The feedback belongs to a single form field — use the field's own help/error text.

| Part | Role | Source |
|------|------|--------|
| Container | Fill (fixed, neutral) | `--nm-message-bg` |
| Container | Shadow | `--nm-message-shadow` — `0 4px 16px` |
| Container | Radius / padding / gap | `border-radius: 8px` · `padding: 8px 12px` · `gap: 16px` |
| Icon | Color | `--nm-message-additional` — recolored per intent |
| Text | Color | `--nm-message-fg` — recolored per intent |
| Link | Color / weight | `--nm-message-additional`, `font-weight: 600`, underlined |

## Accessibility

#### Semantics

- Give the message `role="status"` so assistive tech picks it up as a polite live-region update without stealing focus.
- Mark the icon `aria-hidden="true"` — it duplicates the color/text signal already carried by the message.

#### Focus & dismissal

- A message that appears in response to an action shouldn't steal keyboard focus — announce it, don't move focus to it.
- If a message includes an "Undo" or similar link, make it a real focusable `<button>`/`<a>`, not a styled `<span>` with a click handler.

## Implementation

No JavaScript is required for a static message.

```html
<link rel="stylesheet" href="namirial-theme.css">

<div class="nm-message nm-message--positive" role="status">
  <span class="nm-message__icon" aria-hidden="true"><!-- icon --></span>
  <span>Draft saved</span>
  <span class="nm-message__link">Undo</span>
</div>
```

#### CSS classes

| Class | Values | Default |
|-------|--------|---------|
| `nm-message--{intent}` | primary · secondary · accent · info · positive · negative · warning — omit for `info` | — (`info`) |
| `nm-message__icon` | Leading icon slot, 24×24px | — |
| `nm-message__link` | Inline emphasized link, shares icon color | — |
