## Overview

A popover opens on click (not hover) and stays open until the user dismisses it — by clicking its trigger again, clicking outside, or pressing `Escape`. That persistence is what separates it from a tooltip: a popover can hold interactive content because the user has time to engage with it.

### When to use

Use a popover when:

- The content needs to stay visible while the user reads it or interacts with something inside it (e.g. for contextual help, rich information, interactive guidance).

Consider another component when:

- The content is a short, single-idea hint that only needs to appear on hover/focus — use [Tooltip](/docs/components/messaging/tooltip).
- The content is a full task or requires the rest of the page to be inert while it's open — use a [Dialog](/docs/components/messaging/dialogs).

## Accessibility

#### Semantics

- Give the trigger `aria-haspopup="true"` and `aria-expanded`, toggled with the panel's open state.
- Connect trigger and panel with `aria-controls` pointing at the panel's `id`.

#### Keyboard

- The trigger must open/close the popover on `Enter`/`Space`, not only on click.
- `Escape` closes the popover and returns focus to the trigger.
- Tab must be able to reach every interactive element inside the popover before it can reach anything behind it.

#### Focus

- On open, move focus into the popover only if it contains interactive content the user is expected to use immediately; otherwise leave focus on the trigger.
- On close, always return focus to the trigger.

## Implementation

Positioning and open/close state need JavaScript; the markup and visuals are pure CSS.

```html
<link rel="stylesheet" href="namirial-theme.css">

<div class="nm-popover nm-popover--bottom" role="dialog" id="pop-1">
  <span class="nm-popover__title">Popover</span>
  <hr class="nm-popover__divider">
  <span class="nm-popover__content">Place structured content here for more details.</span>
</div>
```

#### CSS classes

| Class | Values | Default |
|-------|--------|---------|
| `nm-popover--{position}` | top · top-start · top-end · bottom · bottom-start · bottom-end · left · left-start · left-end · right · right-start · right-end | — |
| `nm-popover--{intent}` | primary · secondary · accent · info · positive · negative · warning — omit for `primary` | — (`primary`) |
| `nm-popover__title` | Bold heading row | — |
| `nm-popover__divider` | `<hr>`-style rule between title and content | — |
| `nm-popover__content` | Body content | — |
