This is the Namirial Design System's Component Library. Here you’ll find reusable UI elements designed to help you build consistent, accessible, and responsive user interfaces across our products.

### What’s inside this section

* **Framework-Agnostic Architecture:** Powered by our central design tokens, these components and guidelines are framework-agnostic. Whether you build with React, Vue, Angular, or custom web technologies, the design logic, behaviors, and specifications apply seamlessly across any tech stack.
* **Light & Dark Themes:** Every component is designed and documented with full native support for both Light and Dark modes.
* **Interactive Playground:** Explore each component in real time using the interactive playground to test states, adjust properties, and preview all available configurations.
* **Figma Alignment:** All component specifications directly mirror our official Figma library in terms of variants, states, and naming conventions.
* **Built-in Accessibility:** Designed around WCAG AA guidelines to ensure keyboard navigation and screen reader accessibility out of the box.
