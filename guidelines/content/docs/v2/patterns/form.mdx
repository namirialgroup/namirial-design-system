## Marking required and optional fields

- **Use of asterisks**: it is forbidden to indicate mandatory fields with an asterisk; instead, the indication `(required)` should be used.
- **Forms where most fields are mandatory**: it is advisable to state at the beginning of the form "All fields are required" or "All fields are required unless otherwise indicated", marking the few optional fields with `(optional)`.
- **Forms where most fields are optional**: state "All fields are optional unless otherwise indicated", marking the few mandatory fields with `(required)`. In this case, it's also worth evaluating whether it really makes sense to ask for so many optional fields.
